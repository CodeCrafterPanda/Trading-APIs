# Granular development tasks

Every task below is implementable from this pack without rediscovering architecture. IDs are `T-Exx-nn` (epic, sequence). Phases P0–P6, milestones M0–M6, gates G01–G14 and ADRs are defined in [17](17-IMPLEMENTATION-ROADMAP.md), [19](19-DECISIONS-AND-RISKS.md) and [16](16-SECURITY-AND-COMPLIANCE.md). Effort: S ≤2 days, M ≤1 week, L >1 week for one engineer. Verification lists the acceptance evidence and the failure cases that must be proven. Latency figures are the budgets in [15](15-PERFORMANCE-ENGINEERING.md). "Fixture" means an offline protocol/contract fixture (C5); "live" means authorized broker traffic under a gate.

Definition of done for every task: code merged (no unit tests required; verification evidence is listed per task), fixtures committed, contract/schema version bumped where changed, telemetry counters present, docs cross-reference updated, no brokerage write in CI.
