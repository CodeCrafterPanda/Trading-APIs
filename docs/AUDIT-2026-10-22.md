## Zerodha facts that changed design decisions

- No option-chain, IV or Greeks endpoint → platform ChainBuilder + LOCAL_MODEL Black-76 Greeks become first-class (ADR-06); chain contract unified across brokers with `model_source`.
- No kill switch / exit-all → emergency sequence on Zerodha is per-order reductions; `BROKER_FEATURE_ABSENT` category added.
- Checksum-signed postbacks (SHA-256 of order_id+order_timestamp+api_secret) → the only authenticated webhook; `authenticated_transport` semantics added to 04/11/16.
- Streaming/history need the paid Connect tier; Personal apps are execution-only → gates G13/G14.
- Static IP for order endpoints only with one change per calendar week; 10/s per client ID → 429; 400/min; 5,000/day; 25 modifications/order.
- Token expires at "6 AM" (no timezone label); login elsewhere invalidates.
- Instruments CSV lacks ISIN and freeze quantity; tokens reused after expiry → daily master snapshots cached, cross-mapping via holdings ISIN/external master, freeze from NSE contract file.
- Historical per-interval caps are staff-published (2018/2020), not on the reference page → chunker detects truncation.
